# Legepladser mv. (§ 358 - § 367)

[§ 358](./)

## Legepladser mv.

Projektering, udførelse, drift og vedligehold af legepladsredskaber og -underlag, motionsredskaber i det fri, skateboardbaner og lignende, der er offentligt tilgængelige, skal ske, så der opnås tilfredsstillende sikkerhed mod personskader.\
