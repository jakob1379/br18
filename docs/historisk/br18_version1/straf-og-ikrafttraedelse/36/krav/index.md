# Straf (§ 564)

[§ 564](564)

## Straf

Den, der overtræder bestemmelser som fastsat i bygningsreglementet, straffes med bøde. Bestemmelsen gælder også for byggearbejder, som kan udføres uden ansøgning om byggetilladelse. 

*Stk. 2*. Der kan pålægges selskaber mv. (juridiske personer) strafansvar efter reglerne i straffelovens 5. kapitel for de i stk. 1 nævnte overtrædelser, jf. byggelovens § 30, stk. 5.
